# 구글 스프레드시트 → XLSX 파일 마이그레이션 단계별 실행 계획

## 전체 작업 개요
현재 Google Sheets API 기반 시스템을 로컬 XLSX 파일(`data/GRM_주문_데이터.xlsx`) 기반으로 변경

## 단계별 실행 계획

### PHASE 1: 백엔드 기반 구축 (1-3단계)
#### 목표: XLSX 파일 처리를 위한 백엔드 인프라 구축

### PHASE 2: API 전환 (4-6단계)  
#### 목표: Google Sheets API에서 XLSX API로 전환

### PHASE 3: 프론트엔드 변경 (7-9단계)
#### 목표: 프론트엔드에서 Google API 의존성 제거 및 새 API 연동

### PHASE 4: 마무리 및 최적화 (10-12단계)
#### 목표: 불필요한 코드 정리, 테스트, 배포 준비
