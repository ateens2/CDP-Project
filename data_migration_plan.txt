# 구글 스프레드시트 → 로컬 XLSX 파일 마이그레이션 계획

## 1. 개요
현재 구글 스프레드시트를 중심으로 동작하는 시스템을 data/GRM_주문_데이터.xlsx 파일을 사용하는 방식으로 변경

## 2. 필요한 라이브러리 설치

### 백엔드 (Node.js)
```bash
npm install xlsx multer
npm uninstall googleapis
```

### 프론트엔드 (React)
```bash
npm install xlsx
```

## 3. 백엔드 변경사항

### 3.1 새로운 라우트 파일 생성

### 3.2 기존 파일 수정

#### `/backend/routes/sheets.js` → `/backend/routes/excel.js`로 대체
- **변경사항**:
  - `googleapis` 의존성 제거
  - `XLSX.readFile()` 사용하여 파일 읽기
  - `XLSX.writeFile()` 사용하여 파일 쓰기
  - Google OAuth 인증 제거
  - 모든 엔드포인트를 XLSX 파일 기반으로 변경

#### `/backend/routes/auditLog.js`
- **변경사항**:
  - Google Sheets API 제거
  - XLSX 파일의 'ChangeHistory' 시트 읽기로 변경
  - 로컬 파일 접근으로 변경

#### `/backend/routes/auth.js`
- **변경사항**:
  - Google OAuth 관련 코드 제거
  - 'https://www.googleapis.com/auth/spreadsheets' 스코프 제거
  - 'https://www.googleapis.com/auth/drive' 스코프 제거
  - 로컬 인증 또는 JWT 기반 인증으로 변경

#### `/backend/app.js`
- **변경사항**:
```javascript
// 기존
app.use('/api/sheets', sheetsRoutes);

// 변경 후
app.use('/api/excel', excelRoutes);
```

## 4. 프론트엔드 변경사항

### 4.1 Context 수정
#### `/frontend/src/contexts/UserContext.jsx`

  - 고정된 파일 경로 사용: `/data/GRM_주문_데이터.xlsx`

### 4.2 페이지별 수정사항

#### `/frontend/src/pages/CustomerManagement.jsx`
- **변경사항**:
  - `window.gapi.client.sheets` → 백엔드 API 호출로 변경
  - `fetchSheetData()` → `fetchExcelData()` 함수로 변경
  - `handleSaveChanges()` → 백엔드 API를 통한 XLSX 파일 업데이트
  - Google OAuth 인증 제거
  - API 엔드포인트 변경: `/api/sheets/` → `/api/excel/`

```javascript
// 기존
const resp = await window.gapi.client.sheets.spreadsheets.values.get({
  spreadsheetId: sheet.sheetId,
  range: rangeAll,
});

// 변경 후
const response = await fetch(`${backendUrl}/api/excel/worksheet-data`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    filePath: '/data/GRM_주문_데이터.xlsx',
    sheetName: '고객_정보'
  })
});
```

## 6. 새로운 API 엔드포인트 설계

### 6.1 `/api/excel/` 엔드포인트들
```
GET /api/excel/worksheets - 워크시트 목록 조회
GET /api/excel/worksheet-data - 특정 워크시트 데이터 조회
POST /api/excel/worksheet-data - 워크시트 데이터 추가
PUT /api/excel/worksheet-data - 워크시트 데이터 수정
DELETE /api/excel/worksheet-data - 워크시트 데이터 삭제
POST /api/excel/create-worksheet - 새 워크시트 생성
```

### 6.2 요청/응답 형식
```javascript
// 요청 예시
{
  "filePath": "/data/GRM_주문_데이터.xlsx",
  "sheetName": "고객_정보",
  "range": "A1:K10",
  "data": [...]
}

// 응답 예시
{
  "success": true,
```

## 9. 에러 처리 및 유효성 검사

### 9.1 파일 존재 여부 확인
```javascript
if (!fs.existsSync(filePath)) {
  throw new Error('XLSX 파일을 찾을 수 없습니다.');
}
```

### 9.2 워크시트 존재 여부 확인
```javascript
const workbook = XLSX.readFile(filePath);
if (!workbook.SheetNames.includes(sheetName)) {
  throw new Error('지정된 워크시트를 찾을 수 없습니다.');
}
```
